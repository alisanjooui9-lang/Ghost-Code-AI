👻 Ghost Code AI

Ghost Code AI یک هوش مصنوعی تخصصی برای برنامه‌نویسی است که با هدف درک درخواست کاربران، تولید کد، اصلاح پروژه‌های موجود و ادامه توسعه پروژه‌ها ساخته می‌شود.

🚀 هدف پروژه

هدف Ghost Code AI این است که کاربر بتواند با زبان طبیعی درخواست خود را بیان کند و هوش مصنوعی بتواند:

- 🧠 درخواست کاربر را درک کند
- 💻 کد تولید کند
- 🔧 کدهای موجود را اصلاح کند
- 📁 پروژه‌های چندفایلی را مدیریت کند
- 🔄 قابلیت‌های جدید به پروژه اضافه کند
- 🐛 خطاهای کد را پیدا و اصلاح کند
- 💬 درباره پروژه با کاربر گفتگو کند
- 🧠 سابقه و ساختار پروژه را حفظ کند
- 🌐 در ساخت وب‌سایت کمک کند
- 📱 در ساخت اپلیکیشن کمک کند
- 🎮 در ساخت بازی کمک کند
